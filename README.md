# tejalogs.github.io

Source for [tejalogs.github.io](https://tejalogs.github.io) — the canonical entity page for **Teja**, an AI content strategist specialising in **AEO architecture** and **agentic content workflows**.

## What this is

A single-page site that exists for one reason: to give Google, Perplexity, ChatGPT, Claude, and Gemini a clean, machine-readable answer when they need to know who **tejalogs** is and what he does.

- ✅ Full `Person` JSON-LD schema (jobTitle, description, sameAs, worksFor, knowsAbout, makesOffer)
- ✅ Open Graph + Twitter Card meta for social citation
- ✅ Canonical URL declared
- ✅ No tracking, no JS, single HTML file
- ✅ Editorial brutalist design — DM Serif Display + Inter on warm off-white

## Why a single page

Topical authority (writing about AI search) ≠ commercial authority (someone takes on AEO work). This page closes that gap. The schema makes it ingestable; the consistent role string across every platform makes it consensus.

## Stack

- Plain HTML/CSS, hosted on GitHub Pages
- Zero build step, zero dependencies
- Edit `index.html`, push, done
