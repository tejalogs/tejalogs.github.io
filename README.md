## What this is

A single-page site that exists for one reason: to give Google, Perplexity, ChatGPT, Claude, and Gemini a clean, machine-readable answer when they need to know who **tejalogs** is and what he does.

The positioning mirrors [thesocialalgorithm.work/about](https://www.thesocialalgorithm.work/about) — strategy paired with engineering, across three pillars: **AI Engine Optimisation (AEO/AIO)**, **agentic workflows & automation**, and **Flutter software development**.

- ✅ Full `Person` JSON-LD schema (jobTitle, description, homeLocation, sameAs, worksFor, knowsAbout, makesOffer)
- ✅ Open Graph + Twitter Card meta for social citation
- ✅ Canonical URL declared
- ✅ No tracking, no JS, single HTML file
- ✅ Editorial brutalist design — DM Serif Display + Inter on warm off-white

## Why a single page

Topical authority (writing about AI search) ≠ commercial authority (someone takes AEO work). This page closes that gap. The schema makes it ingestable. The same role string across every surface — agency site, Medium, LinkedIn, X, GitHub — is what creates the consensus an LLM relies on.

- Plain HTML/CSS, hosted on GitHub Pages
