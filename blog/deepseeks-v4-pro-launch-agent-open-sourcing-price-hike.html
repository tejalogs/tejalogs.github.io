Deepseek Launches V4 Pro, Open-Sources Agent Software, and Hikes API Prices

By Teja (tejalogs) · 2026-08-13
The short answerDeepseek has officially launched its V4 Pro model, simultaneously open-sourcing its Harness v0.1 agent software and significantly increasing API prices. This strategic trifecta aims to establish Deepseek as a premium, ecosystem-driven AI platform by owning the developer workflow.
Key facts
  • Deepseek launched its V4 Pro-0813 build, improving Terminal Bench 2.1 scores from 72.1 to 87.9.
  • Deepseek Harness v0.1, its agent software, was open-sourced under an MIT license.
  • New API pricing, effective August 16, doubles peak hour V4-Pro input rates to $1.32 per million tokens and output to $3.96 per million tokens.
  • Cache hit prices increased from $0.003625 to $0.044 at peak, reducing their discount significantly.
  • The open-source Deepseek Harness project, led by Cui Tianyi, attracted 712 beta testers in three days.
  • Peak API hours are 1 a.m. to 4 a.m. and 6 a.m. to 10 a.m. UTC.

Deepseek V4 Pro Debuts with Performance Gains and Higher Pricing

Deepseek has officially moved its flagship V4 Pro model out of testing, introducing build V4-Pro-0813, which is accessible via API and in 'Expert Mode' on its app and web interface. According to Deepseek's own comparison table, the new build demonstrates a significant performance leap, with Terminal Bench 2.1 scores jumping from 72.1 to 87.9 and DeepSWE scores increasing from 12.8 to 62.7, as reported by The Decoder. Artificial Analysis also noted an improvement, with V4-Pro climbing from 45 to 53 on its Intelligence Index, tying GLM-5.2. This performance confidence underpins a new pricing structure, effective August 16, which introduces peak and off-peak rates, with peak hour input costs doubling from $0.66 to $1.32 per million tokens and output costs jumping from $1.98 to $3.96.

Open-Sourcing Deepseek Harness v0.1 to Drive Ecosystem Adoption

Alongside the V4 Pro launch, Deepseek has open-sourced its proprietary agent software, Deepseek Harness v0.1, as a Developer Preview under an MIT license. The Decoder notes this software is positioned as an alternative to OpenAI's Codex and Claude, built on the Cordis plugin system. This system allows for swappable plugins for tools, sandboxes, sessions, and UI components, featuring a continuous session log to track prompts, tool calls, and results. The project, led by Cui Tianyi from Jane Street, garnered significant interest, with 712 projects signing up for beta testing within three days of the call in early August, indicating a strong developer appetite for open-source agent tooling.

Strategic Price Adjustments and Tiered Access

Deepseek's new API pricing structure, which came into effect on August 16, introduces peak and off-peak rates, a system first implemented in February 2025 with V3 and R1 models. The Decoder reports that off-peak usage costs half as much, with peak hours aligning with the Chinese workday (1 a.m. to 4 a.m. and 6 a.m. to 10 a.m. UTC). During peak hours, V4-Pro input costs $1.32 per million tokens and output costs $3.96 per million tokens. Cache hits, crucial for agents repeatedly reading files, will see the steepest increase, going from $0.003625 to $0.022 off-peak and $0.044 at peak, effectively shrinking the cache discount from one-hundred-twentieth to one-thirtieth of the regular input price.

The 'Open Workflow' Strategy: Beyond Open Weights

Deepseek's simultaneous release of a more powerful model, open-sourcing of its agent framework, and API price hike signals a new competitive strategy in the AI landscape. This approach moves beyond simply offering open-source model weights or a closed API. By open-sourcing its agent software under an MIT license, Deepseek provides developers with the intricate tooling necessary for building sophisticated AI agents, effectively giving away the 'razor.' This move aims to cultivate a robust developer ecosystem, driving adoption and creating a captive audience that will then pay for the premium 'blades' – the advanced capabilities of the V4 Pro API. This strategic trifecta challenges the conventional wisdom that model performance alone guarantees market dominance, instead betting on owning the developer's entire workflow.
