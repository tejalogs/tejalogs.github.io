Xiaomi MiMo-V2.5-Pro-UltraSpeed Reaches 1000 Tokens/Second: The Real-Time AI Shift

By Teja (tejalogs) · 2026-06-09
The short answerXiaomi, in partnership with TileRT, has released MiMo-V2.5-Pro-UltraSpeed, a 1-trillion-parameter model capable of 1000 tokens per second. This benchmark fundamentally changes expectations for real-time AI, making truly instant interaction a core requirement for large language models.
Key facts
  • Xiaomi's MiMo-V2.5-Pro-UltraSpeed achieves 1000 tokens per second.
  • The model is a 1-trillion-parameter large language model.
  • This benchmark was achieved in partnership with TileRT.
  • A 500-token response can be generated in 0.5 seconds.
  • The speed redefines expectations for real-time AI interaction and user experience.

Unprecedented Speed for 1-Trillion-Parameter Models

Xiaomi and TileRT's MiMo-V2.5-Pro-UltraSpeed has achieved a decode speed of 1000 tokens per second for a 1-trillion-parameter model. This breakthrough represents a significant leap in inference speed, delivering a 500-token detailed response in half a second, outpacing current commercial LLMs in raw generation speed for complex outputs.

Elevating User Experience Standards for AI

The 1000 tokens per second benchmark means user expectations for AI responsiveness are drastically escalating. Indie builders and developers must now prioritize inference optimization, as applications failing to deliver near-instantaneous responses for sophisticated queries will struggle with user adoption and retention, requiring re-evaluation of current inference strategies.

The Dawn of 'AI as an Extension of Thought'

This speed advancement signifies a broader industry shift where AI's utility is tied to its ability to become a seamless, real-time cognitive partner. Successful AI products will increasingly hinge on minimizing latency to the point where the AI's processing time is imperceptible, enabling new intuitive, 'always-on' intelligent systems rather than task-based tools.
